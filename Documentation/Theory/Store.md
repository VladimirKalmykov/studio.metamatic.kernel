Алиасы
--

Получение виртуального Store, который не связан с конкретным объектом, но прослушивет указанный алиас, который может уже содержать объект.

Создание алиса:

```csharp
/* Создавая алиас "CurrentPlayer" мы указываем, что данный алиас будет прослушивать Store с адресом "1" */
MicroStore<MyData>.SetAlias("CurrentPlayer", "1");
```

Получение Store по алиасу:

```csharp
using var store = MicroStore<MyData>.Alias("CurrentPlayer");
store.value; // Содержит значение Store с адресом "1"
MicroStore<MyData>.SetAlias("CurrentPlayer", "2");
store.value; // Содержит значение Store с адресом "2"
```

Создавая Store через алиас мы получаем ссылку на MictoStoreAlias<T> - его API идентично MicroStore, за некоторыми исключениями.
Например, подписка на изменения значений будет учитывать возможность смену значения алиаса, таким образом мы всегда будем получать актуальные данные для разных хранилищ без необходимо переключаться между ними вручную

Если алиас не был указан, то Store будет привязан к значению "default". Однако если алиас будет указан уже после подписки на Store, то Store будет автоматически переключен на новое значение.

И _MicroStore<T>_ и _MicroStoreAlias<T>_ реализуют интерфейс _IStore<T>_, что позволяет использовать их в качестве аргументов в методах, которые ожидают IStore<T> в качестве аргумента.

Методы IStore<T>:
--

### Checkout

Создает копию состояния Store и помещает ее в отдельную - ветку. Ветка по-умолчанию называется "default". При переключении ветки, предыдущая ветка не удаляется, а остается в памяти, и к ней можно вернуться в любой момент.

```csharp
using var store = MicroStore<MyData>.Default();
store.Checkout("new");
// Теперь ветка "new" содержит копию состояния Store
store.Checkout(); // Переключаемся на ветку "default"
```

По-умолчанию копия ветки создается из ветки "default". Однако можно указать другую ветку, из которой будет создана копия.

```csharp
using var store = MicroStore<MyData>.Default();
store.Checkout("new", "default");
```

Ветка переключается для всех подписчиков на Store, что позволяет им получать состояние уже из новой ветки.

> Переключение между ветками полезно когда нужно создать временное состояние, которое не должно влиять на основное состояние Store. Например, при попадания игрока в гардеробную, можно создать ветку "wardrobe", в которой будет осуществляться примерка вещей, при этом в ветке default будет оставаться оригинальное состояние.

### Merge

Смержить состояние одной ветки в другую. 

```csharp
using var store = MicroStore<MyData>.Default();
store.Checkout("new");
store.Merge("new", "default");
```

Так же метод может принимать функцию, которая принимает текущее состояние ветки, из которой производится merge, и возвращает новое состояние для ветки, в которую происходит merge.

```csharp
using var store = MicroStore<MyData>.Default();
store.Checkout("new");
store.Merge("new", "default", data => {
    data.level = 5;
    return data;
});
```

### Populate

Метод предназначен для трансформации данных в Store во всех ветках.

```csharp
store.Populate(data => {
    data.level = 5;
    return data;
});
```

Такой подход полезен когда мы содержим Store сразу в нескольких именных состояниях, но хотим применить изменения ко всему Store, а не к одной ветке.
