InterpolateTargetsPositionSource
--

Компонент позволяет виртуализировать позицию исходя из позиции другого объекта-цели (target). Если target будет изменен, то виртуальная позиция будет выстроена между предыдущей целью и новой с интерполяцией по алгоритму easing с временем (transition duration).

![](lerpposition.gif)

Компонент не изменяет позицию объекта самостоятельно. Для изменения его позиции используется скрипт:

```c#
 transform.position = positionSource.position;
```

По-умолчанию текущей целью является сам объект, что бы динамически поменять цель используйете свойство _target_.

```c#
positionSource.target = someTarget;
```

## Особенности компонента

- Компонент помнит все предыдущие цели до момента истечения _transition duration_ для каждой из них. То есть если цель поменялась несколько раз за время анимации, интерполяция будет учитывать все цели, а не только последнюю.
